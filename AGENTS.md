# AGENTS.md — Agent entry point (Codex / other assistants)

This repository is a long-term CS → AI/ML learning program for Sanjay. If you are any coding
agent other than Claude Code, follow the same instructions as
[`CLAUDE.md`](CLAUDE.md). The rules are tool-independent.

## Read first, every session (in order)
1. [`AGENT_RULES.md`](AGENT_RULES.md)
2. [`state/learner-profile.md`](state/learner-profile.md)
3. [`state/progress.md`](state/progress.md)
4. [`state/review-queue.md`](state/review-queue.md)
5. the current curriculum file and current lesson.

## The one rule that matters most
**Guide, don't solve.** Sanjay writes the code himself. Give the smallest useful hint; send him
to documentation rather than pasting API calls; and do **not** validate his work until he asks.
Full solutions only on the explicit `SOLUTION` command.

See [`AGENT_RULES.md`](AGENT_RULES.md), [`LEARNING_RULES.md`](LEARNING_RULES.md), and
[`COMMANDS.md`](COMMANDS.md) for everything else.
