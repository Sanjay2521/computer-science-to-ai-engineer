# MILESTONES

Milestones are defined by **demonstrated ability**, not by time elapsed or lessons read. You
reach one when you can produce the evidence listed — verified against the four mastery levels in
[`LEARNING_RULES.md`](LEARNING_RULES.md).

## M0 — Beginner (method installed)
*Covers Phase 0.*
- Run a 2-hour study session unaided and record evidence.
- Maintain the review queue and progress tracker.
- Environment working: Python + venv, Git, VS Code, PowerShell.
- **Evidence:** Day 1–7 complete with recorded results; trackers in active use.

## M1 — Foundational (how computers & code work)
*Covers Phases 1–2.*
- Trace a value from binary → gates → CPU register; explain fetch-decode-execute.
- Implement a mini instruction emulator.
- Write idiomatic, tested Python; explain a C segfault; drive Git confidently.
- **Evidence:** projects #1–6; passing checkpoint assessment for P1–P2.

## M2 — Problem solver (DSA + math spine)
*Covers Phases 3.*
- Choose and justify a data structure; analyze time/space complexity.
- Implement gradient descent by hand; connect linear algebra to code.
- Solve medium DSA problems across the core patterns, logged with evidence.
- **Evidence:** projects #7–8; DSA tracker shows independent solves across patterns; math
  tracker shows implemented concepts.

## M3 — Systems engineer (OS, net, db, software eng)
*Covers Phases 4–5.*
- Explain context switches, TCP handshake, DB index; build an HTTP server and a REST API.
- Design a small service and defend its trade-offs; write a real test suite + CI.
- **Evidence:** projects #9–13; system-design checkpoint passed.

## M4 — Scale & data (distributed, cloud, data engineering)
*Covers Phase 6.*
- Explain CAP with a concrete scenario; reason about retries, idempotency, delivery semantics.
- Build a resilient data pipeline; containerize a service.
- **Evidence:** projects #14–15.

## M5 — Intermediate ML (classical ML)
*Covers Phase 7.*
- Implement linear/logistic regression and a decision tree from scratch.
- Diagnose over/underfitting; build a leak-free evaluation harness.
- **Evidence:** projects #16–19.

## M6 — Deep learning practitioner
*Covers Phase 8.*
- Derive and implement backprop; build an autograd engine; train a PyTorch model.
- Debug a model that won't train.
- **Evidence:** projects #20–22.

## M7 — Transformer/LLM internals
*Covers Phase 9.*
- Implement self-attention and a transformer block from scratch; train a tiny GPT.
- Explain KV cache, sampling strategies, and tokenization.
- **Evidence:** projects #23–26.

## M8 — AI engineer (RAG + production LLM apps)
*Covers Phase 10.*
- Build RAG without hiding the pipeline; measure retrieval and answer quality.
- Add structured outputs, guardrails, tracing, cost/latency awareness.
- **Evidence:** projects #27–28.

## M9 — Job-ready (agents, MCP, computer use)
*Covers Phase 11.*
- Build an agent loop from scratch; build an MCP server/client; a browser and a sandboxed
  computer-use agent; a simplified coding agent.
- Explain and mitigate prompt injection; apply least privilege and approval gates.
- **Evidence:** projects #29–34; security checkpoint passed.

## M10 — Research-capable (ops, security, research)
*Covers Phase 12.*
- Deploy and monitor a production AI service; threat-model an agent.
- Reproduce a research paper's baseline; run an ablation; write a technical report.
- **Evidence:** projects #35–36; one reproduced paper in
  [`state/paper-reading-log.md`](state/paper-reading-log.md).

---
Advancement is gated on evidence, verified at checkpoint assessments (~every 4 weeks). A
milestone can be revisited — "Needs review" is a normal state, not a failure.
