# Computer Science → AI/ML Engineer

A long-term (≈2–3 year) self-directed learning repository that rebuilds computer-science
foundations from the ground up and carries them all the way to production AI systems and
agents.

**Owner:** Sanjay · **Started:** 2026-10-11 · **Pace:** ~2 hrs/day, ~12–14 hrs/week

---

## Purpose

To go from *using* technology to *understanding* it. The goal is not `pip install → import →
call API`. The goal is to be able to **explain, implement, test, debug, and connect** every
layer of the stack:

> transistors → logic gates → CPU → machine code → OS → programming languages → data
> structures → algorithms → networking → databases → software engineering → distributed
> systems → mathematics → data engineering → machine learning → deep learning → attention →
> transformers → LLMs → embeddings → retrieval → RAG → tool calling → MCP → agents →
> browser/computer-use agents → coding agents → production AI → AI research

## Final goal

Become a strong end-to-end AI/ML engineer who can read and reproduce research, build systems
from scratch before reaching for frameworks, and debug across abstraction layers.

## Working with a coding agent (Claude Code / Codex)

This repo is designed to be driven with an AI coding assistant acting as your instructor.
- Agent entry points: [`CLAUDE.md`](CLAUDE.md), [`AGENTS.md`](AGENTS.md)
- Rules the agent must follow: [`AGENT_RULES.md`](AGENT_RULES.md)
- Commands you can give it (TEACH, HINT, REVIEW, DEBUG, QUIZ, NEXT DAY, …):
  [`COMMANDS.md`](COMMANDS.md)

**Important working style:** when you hit a coding task, *you* write the code. The agent
guides with hints, points you to documentation, and only gives full solutions when you
explicitly ask (`SOLUTION MODE`). See [`LEARNING_RULES.md`](LEARNING_RULES.md).

## Main learning principles

1. **Learn in layers** — intuition → model → example → formal → implement → test → debug → connect.
2. **From scratch before abstraction** — build a simplified version before using the library.
3. **Evidence-based mastery** — four levels, nothing marked done without proof.
4. **Active learning** — question → attempt → hint → explanation, never answer-first.
5. **Sustainable scope** — the repo grows with you; it is not pre-filled with years of lessons.
