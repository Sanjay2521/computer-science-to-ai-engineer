# RESOURCES

Curated, dependency-ordered resources. These are **pointers and descriptions only** — no copied
course content or copyrighted books. Clone or fork a repo **only** when its module becomes
active and there's a clear learning purpose.

> When internet access is available, verify links are current before relying on them, and prefer
> official/primary sources. If a resource is unavailable, note it rather than silently dropping
> it.

## Meta: learning how to learn (Phase 0)
- **Learning How to Learn** (Coursera / Barbara Oakley) — active recall, spaced repetition.
- **The Missing Semester of Your CS Education** (MIT) — shell, Git, debugging, tooling.
- **Teach Yourself CS** (teachyourselfcs.com) — the canonical self-study reading list.
- **OSSU Computer Science** (github.com/ossu/computer-science) — structured open curriculum.

## Phase 1 — Computer systems
- **Nand2Tetris** (nand2tetris.org) — build a computer from NAND gates up. Core of this phase.
- **CS:APP — Computer Systems: A Programmer's Perspective** — use selectively for depth.
- **Crafting Interpreters** (craftinginterpreters.com) — later, for language/VM intuition.
- **Build Your Own X** (github.com/codecrafters-io/build-your-own-x) — project inspiration.

## Phase 2 — Programming, C, tooling
- **Official Python docs & tutorial** (docs.python.org) — primary source.
- **CS50** (Harvard) — C and foundational programming.
- **Pro Git book** (git-scm.com/book) — free, authoritative.
- **PowerShell docs** (learn.microsoft.com/powershell) — Windows CLI.

## Phase 3 — DSA & mathematics
- **MIT 6.006 Introduction to Algorithms** (OCW) — algorithms with rigor.
- **3Blue1Brown — Essence of Linear Algebra / Calculus** (YouTube) — intuition first.
- **Khan Academy** — probability, statistics, calculus fundamentals.
- **Mathematics for Machine Learning** (mml-book.github.io) — free book bridging math→ML.

## Phase 4 — OS, networking, databases
- **Operating Systems: Three Easy Pieces** (ostep.org) — free, excellent.
- **Beej's Guide to Network Programming** (beej.us) — sockets hands-on.
- **Computer Networking: A Top-Down Approach** — conceptual backbone.
- **Use The Index, Luke** (use-the-index-luke.com) — SQL indexing.

## Phase 5–6 — Software eng, distributed, cloud, data
- **Designing Data-Intensive Applications** (Kleppmann) — the distributed-systems bible.
- **Docker / Kubernetes official docs** — containers and orchestration.
- **The Twelve-Factor App** (12factor.net) — service design principles.
- **Pandas / NumPy official docs** — data engineering foundations.

## Phase 7 — Classical ML
- **scikit-learn user guide** (scikit-learn.org) — after from-scratch implementations.
- **An Introduction to Statistical Learning** (ISLR, statlearning.com) — free, approachable.
- **Made With ML** (madewithml.com) — applied ML + MLOps.

## Phase 8 — Deep learning
- **Dive into Deep Learning** (d2l.ai) — free, code-first.
- **fast.ai** (course.fast.ai) — practical DL.
- **Karpathy — Neural Networks: Zero to Hero** (YouTube) + **micrograd** (github.com/karpathy/micrograd).
- **PyTorch official tutorials** (pytorch.org).

## Phase 9 — Transformers & LLMs
- **Karpathy — nanoGPT** (github.com/karpathy/nanoGPT) + "Let's build GPT" lecture.
- **"Attention Is All You Need"** (the transformer paper) — read after implementing attention.
- **The Illustrated Transformer** (jalammar.github.io) — visual intuition.
- **LLMs from Scratch** (Sebastian Raschka, github.com/rasbt/LLMs-from-scratch).
- **Hugging Face course** (huggingface.co/learn) — practical NLP/LLM.

## Phase 10 — RAG & AI engineering
- **Full Stack Deep Learning** (fullstackdeeplearning.com) — productionizing.
- **Official provider docs** for whatever model API you use (primary source for current features).
- Build retrieval and embedding search from scratch before adopting a RAG framework.

## Phase 11 — Agents, MCP, computer use
- **Model Context Protocol docs** (modelcontextprotocol.io) — the MCP spec.
- **Playwright docs** (playwright.dev) — browser automation.
- **Microsoft — AI Agents for Beginners** (github.com/microsoft/ai-agents-for-beginners).
- **Microsoft — Generative AI for Beginners** (github.com/microsoft/generative-ai-for-beginners).
- Build a minimal agent loop before adopting any agent framework.

## Phase 12 — MLOps, security, RL, multimodal, research
- **Made With ML** / **Full Stack Deep Learning** — MLOps.
- **OWASP Top 10 for LLM Applications** — security threats (injection, excessive agency, etc.).
- **Spinning Up in Deep RL** (OpenAI, spinningup.openai.com) — RL foundations.
- **arXiv + Papers With Code** — research and reproducible baselines.

## Resource discipline
- Don't clone dozens of repos or dump unordered links.
- Don't copy copyrighted books or complete course content.
- Record *why* a resource is useful and its prerequisites before relying on it.
- Prefer one good resource per topic over many equivalents.
