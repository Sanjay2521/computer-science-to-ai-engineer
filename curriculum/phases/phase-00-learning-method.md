# Phase 0 — Learning Method & Environment

**Timeline:** ~1–2 weeks · **Module:** [00-learning-how-to-learn](../../modules/00-learning-how-to-learn/)

## Goal
Install a durable learning system and a working toolchain so every later phase compounds.

## Prerequisites
None.

## Topics & required depth
- **Learning science (apply, don't just read):** active recall, spaced repetition, deliberate
  practice, interleaving, the Feynman technique, debugging your own mental models,
  note-taking without passive copying, project retrospectives.
- **Meta-skills:** how to read documentation, how to ask good technical questions, how to use AI
  assistants without becoming dependent.
- **Environment:** PowerShell basics, VS Code, Python + virtual environments, Git init.

## Mathematics / DSA threads
Not yet — this phase is about *how* to learn. Number bases get introduced in Week 1 (Phase 1).

## Hands-on labs
- Set up Python venv, VS Code, Git.
- Run a first `REVISE` cycle on a trivial fact to feel the mechanics.
- Write one Feynman explanation of "what active recall is and why it works."

## From-scratch implementation
N/A (methodology phase).

## Mini-project
Get this repository into active use: trackers seeded, Day 1 scheduled.

## Major project
None (the repo *is* the deliverable).

## Recommended resources
Learning How to Learn; The Missing Semester; Teach Yourself CS. (See [`../../RESOURCES.md`](../../RESOURCES.md).)

## Assessment
Run one full 2-hour session unaided and record evidence; demonstrate a `REVISE` cycle.

## Exit criteria
- You can run a study session, record evidence, and manage the review queue without help.
- Environment works: Python, venv, Git, VS Code, PowerShell.

## Common mistakes
- Passive re-reading mistaken for studying.
- Skipping the trackers "just this once."
- Over-engineering the setup instead of starting.

## Connection to next phase
Method and tools in place → start building the mental model of the machine itself in Phase 1.
