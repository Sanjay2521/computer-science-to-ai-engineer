# Python Basics Ladder (P1–P9)

A gentle, graded path to learn the **ABCs of Python** before tackling the number-system converter
(Project #1) from scratch. One tiny concept per step, 3–5 micro-problems each. Format:
**teach-then-practice** — a short worked example first, then you solve the problems yourself.

> This is your beginner-level practice loop: solve → save → push. No LeetCode yet — that's Phase 3
> (DSA), months away; its free tier is plenty when you get there, so don't buy Premium.

in `notes/`.

## How to work a step
1. Open the step file. Read the worked example at the top (that's the "teach" part).
2. Solve the numbered problems below it — write your code where it says `# your code here`.
3. Run it: `python exercises/python-basics/pNN_name.py`
4. Say `REVIEW` when you want feedback. Then `git add -A; git commit; git push`.

After P9, we return to Project #1 — and it'll feel easy.
