# Module 00 — Learning How to Learn

## Purpose
Install the learning system that makes every later module compound: active recall, spaced
repetition, deliberate practice, and honest self-assessment.

## Prerequisites
None.

## Topics
Active recall · spaced repetition · deliberate practice · interleaving · Feynman technique ·
debugging mental models · note-taking without passive copying · project retrospectives · reading
documentation · asking good technical questions · using AI assistants without dependency.

## Learning outcomes
- Run a focused 2-hour session and capture evidence.
- Use the review queue and spacing intervals correctly.
- Write a Feynman explanation that exposes gaps.

## Exercises
- First `REVISE` cycle on a trivial fact.
- Write a teach-back of "why active recall beats re-reading."

## Projects
None (the repo itself is the deliverable).

## Exit criteria
Run a session unaided; manage the review queue; environment working.
