# Module 02 — Programming (Python, C, Git, Shell, Testing)

## Purpose
Become fluent in Python, see memory directly with a taste of C, and adopt professional tooling.

## Prerequisites
Module 01.

## Topics
Python deeply (types, references/mutability, control flow, functions/scope, recursion, modules/
packages, venv, files, exceptions, OOP, iterators/generators, comprehensions, decorators, context
managers, type hints, dataclasses, testing, debugging, logging, profiling, threads/processes,
async, packaging, standard library) · C (compilation, linking, pointers, structs, stack/heap,
memory errors, segfaults) · PowerShell & CLI · Git (commits, branches, merges, diffs, rebase
concepts) · debuggers.

## Learning outcomes
- Write idiomatic, typed, tested Python.
- Explain pointers and reproduce/diagnose a segfault.
- Drive Git and the shell confidently, including a merge conflict.

## Exercises
- Mutability & closure gotchas; generator vs list.
- Write a decorator and a context manager.
- C: print addresses, allocate on the heap, trigger and fix a segfault.
- pytest suite for a small module.

## Projects
#4 C memory experiments · #5 command-line utility · #6 mini shell.

## Exit criteria
Idiomatic tested Python; segfault explained; confident Git/shell.
