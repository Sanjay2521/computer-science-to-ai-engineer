# Module 03 — Data Structures & Algorithms

## Purpose
Solve problems with the right structure and algorithm; reason about cost. Learn patterns and
invariants, not memorized solutions.

## Prerequisites
Module 02.

## Topics
Complexity (Big-O/Θ/Ω) · arrays, strings, linked lists, stacks, queues, deques, hash tables, sets
· recursion, binary search, sorting · trees, BSTs, balanced-tree concepts, heaps/priority queues,
tries · graphs, BFS/DFS, union-find, topological sort, shortest paths, MST · patterns: two
pointers, sliding window, prefix sums, monotonic stack, greedy, backtracking, divide & conquer,
dynamic programming, bit manipulation.

## Learning outcomes
- Choose and justify a structure; analyze time/space complexity.
- Implement each core structure from scratch with tests.
- Solve unseen medium problems across every pattern.

## Exercises
Log every problem in [`../../state/dsa-tracker.md`](../../state/dsa-tracker.md) (problem, idea,
approach, complexity, mistake, hint level, independent?, retry date).

## Exit criteria
Core structures from scratch; independent solves logged across patterns; fluent complexity
analysis.
