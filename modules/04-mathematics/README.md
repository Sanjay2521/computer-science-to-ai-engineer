# Module 04 — Mathematics for AI & Computing

## Purpose
Build the math spine for ML: linear algebra, probability/statistics, calculus/optimization, and
information theory — intuition first, then notation, then code.

## Prerequisites
Module 02 (functions, logs). Runs as a **parallel thread** alongside Modules 03–10.

## Topics
Foundations (functions, logs/exponents, sequences, summations) · linear algebra (vectors, dot
products, matrices, matmul, linear transformations, basis/dimension, eigen-intuition) ·
probability (conditional, Bayes, random variables, distributions, expectation/variance/covariance,
sampling) · statistics (descriptive, inferential, hypothesis-testing intuition) · calculus
(limits, derivatives, partials, gradients, chain rule, optimization, gradient descent, convexity)
· information theory (entropy, cross-entropy, KL divergence).

## Learning outcomes
- Implement dot product, matmul, and gradient descent from scratch and verify by hand.
- Explain Bayes with a concrete example; derive cross-entropy from entropy.
- Connect every major idea to a computing/ML use (logged).

## Projects
Gradient descent from scratch (reused in Modules 08–09).

## Exit criteria
Each idea: intuition + formula + working code + a logged connection to ML.
