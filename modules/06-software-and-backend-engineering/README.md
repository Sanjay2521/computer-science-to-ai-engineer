# Module 06 — Software & Backend Engineering

## Purpose
Write maintainable systems and reason about design trade-offs; build a real backend service.

## Prerequisites
Modules 02 and 05.

## Topics
Requirements, decomposition, clean code, coupling/cohesion, OOP + SOLID (as guidance), design
patterns, refactoring · testing (unit/integration/e2e, doubles, property-based concepts) · error
handling, logging, config, docs, code review, CI/CD, versioning, dependency management, security
fundamentals · backend (APIs, services, auth, background jobs, queues, caches, storage, DB
integration) · system design (scaling, load balancing, rate limiting, HA, observability, fault
tolerance, capacity estimation, trade-offs).

## Learning outcomes
- Build and operate a tested, documented, observable REST API with CI.
- Reason explicitly about coupling, testing strategy, and scaling trade-offs.

## Exercises
Refactor a messy module; build a test pyramid; add logging/metrics/tracing; a capacity estimate.

## Projects
#10 REST API (DB + tests + CI + observability).

## Exit criteria
Ship a tested, observable API; defend a small system design.
