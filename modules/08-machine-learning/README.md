# Module 08 — Machine Learning

## Purpose
Understand learning from data from first principles; implement core algorithms before scikit-learn.

## Prerequisites
Module 03 (math spine) and Module 07 (data).

## Topics
What learning means · supervised/unsupervised · train/val/test, data leakage · linear & logistic
regression, KNN, naive Bayes, decision trees, random forests, gradient boosting, SVM concepts ·
k-means, PCA · feature engineering, preprocessing, missing data, class imbalance · loss functions,
optimization, regularization, bias/variance, cross-validation, metrics, calibration,
hyperparameter tuning, explainability, reproducibility, baselines, experiment design.

## Learning outcomes
- Implement linear/logistic regression and a decision tree from scratch, verified vs scikit-learn.
- Diagnose over/underfitting; build a leak-free evaluation harness; justify a metric.

## Exercises
Leak-free split; cross-validation from scratch; learning curves; detect a planted leakage bug.

## Projects
#16 linear regression · #17 logistic regression · #18 decision tree · #19 ML evaluation project.

## Exit criteria
Three algorithms from scratch; honest leak-free evaluation with a baseline.
