# projects/

The 36-step project ladder lives here — one folder per project (e.g. `01-number-system-converter/`).
Each project folder should contain its code, tests, and a short `RETROSPECTIVE.md`.

See [`../PROJECTS.md`](../PROJECTS.md) for the ladder and
[`../state/project-log.md`](../state/project-log.md) for status. Projects #32–34 (browser /
computer-use / coding agents) must run in local sandboxes with disposable data — see
[`../AGENT_RULES.md`](../AGENT_RULES.md) §Safety.
