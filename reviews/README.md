# reviews/

Checkpoint assessments (~every 4 weeks) and their results. One file per checkpoint, e.g.
`checkpoint-01.md`. Checkpoints mix explain / trace / implement / debug / complexity / design /
transfer questions. Per [`../LEARNING_RULES.md`](../LEARNING_RULES.md), exams don't change progress
until reviewed, and no topic is "mastered" on multiple-choice alone.
